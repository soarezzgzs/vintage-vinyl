
# 📊 Vintage Vinyl

**Vintage Vinyl** é um site desenvolvido para apresentar os discos do **Paulo Soares** e divulgar seu estoque de discos / vinis.

---

## 🌐 Demonstração
Acesse o site publicado no Netlify:  
👉 https://vintage-vinyl.netlify.app
